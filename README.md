# From Social to Screen

Interface minimale : accueil vide, Ma veille et Connexions à gauche, Compte en haut à droite.

Création de compte, connexion et déconnexion via Supabase. Les clés restent dans la fonction serveur. Inscription immédiate sans vérification e-mail dans cette version. La session utilisateur reste dans l’onglet.

Aucune donnée métier prédéfinie. Ma veille et Connexions restent à concevoir. Aucun secret, document fourni, compte ou donnée privée dans ce dépôt.
